# Deployment Rule
Whenever code changes are made to the local project files, automatically run the `npm run deploy` command in `cleanmax website 1` to push the updates to the live GitHub Pages website as well. Do this proactively without waiting for the user to ask, and inform them once the deployment starts or completes.

# Dual Update Rule
Whenever changes are requested to the codebase, ALWAYS apply those same changes to both `cleanmax website 1` and `cleanmax website 2` unless specifically instructed otherwise.
